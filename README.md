# Charles Miedema

I build Python tools for logistics ops and LLM evaluation — shipment exception triage, document extraction, preference labeling, and guardrails for tool-using agents.

Mostly interested in systems that stay reliable when something fails: checkpoints, clear policies, tests you can re-run without an API key.

## Projects

**[LoadWatch](https://github.com/cmiedema25-rgb/loadwatch-shipment-exceptions)** — Turns a TMS shipment export into a routed exception queue (dispatch vs tracking vs safety), with checkpointed runs and optional signed webhook alerts.

**[LLM Evaluation Lab](https://github.com/cmiedema25-rgb/llm-evaluation-alignment-lab)** — Score responses, run prompt regression checks, label preferences, and export chosen/rejected pairs for alignment work.

**[Document Intelligence Pipeline](https://github.com/cmiedema25-rgb/document-intelligence-pipeline)** — OCR-aware classification and field extraction with provenance, plus a small HTTP API and TypeScript SDK.

**[Secure Agent Runtime](https://github.com/cmiedema25-rgb/secure-agent-runtime)** — Policy gateway for tool-using agents: injection checks, capability allowlists, tamper-evident audit log.

Also: [semi-truck trip planner](https://github.com/cmiedema25-rgb/semi-truck-trip-planner), [business ROI automation](https://github.com/cmiedema25-rgb/business-roi-automation).
